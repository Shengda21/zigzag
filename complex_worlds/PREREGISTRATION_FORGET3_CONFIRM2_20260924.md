## 1. 为什么修订统计程序

第一次确认预注册（`PREREGISTRATION_FORGET3_CONFIRM_20260924.md`）沿用论文 §3.3 的零模型：逐转移端点数 T_{k,t}、相邻检查点置换、B=1000、Bonferroni。结果在 5 个确认臂上最小 p = 0.35–0.41，没有任何转移显著；因此严格按那份预注册，第一次确认只能算"部分成立"。

诊断（`cloud_return_round2/analysis/null_power.py`、`null_total.py`）表明这不是实现偏差：换成论文原文的"同一置换作用于所有胞腔"或全局打乱，结果仍不显著。原因在统计量本身。打乱时间轴会在每个转移上制造端点，全局打乱后端点总数是观测值的 5–7 倍，所以"这个转移处端点是否偏多"对真实的阶跃没有检验力。反过来，观测轨迹比零模型平滑得多：总端点数下尾 p = 1/201，已经到了置换次数的下限。

所以把两件事拆开：
- 单个事件是否可信，由题目簇 bootstrap 和跨臂复现来回答；
- 置换零模型只检验一个全局问题：拓扑轨迹在训练时间上是否有组织。

## 2. 修订后的统计程序（本轮起适用于所有线）

**S1 胞腔分数与簇。** 胞腔分数的定义与第一次确认相同：顶点 = 读出准确率，边 = 转换准确率（模板 0、1），面 = 联合任务 min(替换, 不替换)。重采样单位是题目簇 (task, item)：同一 item 的全部模板和替换/不替换变体共享一个权重。

**S2 题目簇 bootstrap。** 共 B = 1000 次重复。每次重复里，对每个 task 独立地有放回抽取与原数目相同的 item；同一次抽样作用于该臂的全部检查点，因为题目集在检查点之间固定。在重抽数据上重算全部胞腔分数、K_t(θ)、条形码与事件分类，判据按与点估计完全相同的规则判定。判据 c 的支持度 s_c = 满足 c 的重复所占比例。

判据 c **稳健成立**的条件：点估计成立，并且 s_c ≥ 0.95。

**S3 时间组织检验（保留置换零模型，改用全局统计量）。**
- 统计量 E_tot：整个复形上 H₀ 与 H₁ 的 zigzag 端点总数（并集桥接），在 Θ 上取平均。
- 零模型：检查点顺序做均匀随机置换，同一置换作用于所有胞腔，B = 1000。
- 检验：单侧下尾，p = (1 + #{E_tot^(b) ≤ E_obs}) / (B + 1)。要求 p ≤ 0.01。

S3 回答的是"拓扑变化与训练时刻对应、不可交换"，不单独为某个事件背书。

**S4 跨臂复现。** 以臂为单位计数，见 §3 末尾的成功定义。

阈值网格 Θ = {0.60, 0.65, …, 0.90}；检查点间隔 16 步；"≥5/7 阈值"指 Θ 中至少 5 个阈值满足。

## 3. FORGET3 SFT 臂（世界 635、636、637 × 种子 1、2 = 6 臂）

模型与训练和第一次确认相同：Qwen2.5-1.5B-Instruct + LoRA r16/α32，对话模板，只在答案上计损失，768 步，batch 64，micro 16，每 16 步评测全部 3712 条探针。

**子复形。** 判据在以下限制上判定。它们都是 K* 的闭子复形，K_t(θ) 与它们的交仍是闭子复形：
- K_B = {B1–B4；B1B2、B2B3、B1B3、B3B4 及其替换边 B1B2r、B2B3r、B1B3r、B3B4r；B2B4；fB123、fB234}；
- K_C = {C1–C4；C1C2、C2C3、C1C3、C3C4；fC123}。

**判据（每臂分别判定；时间单位为训练步，"在 t"指检查点 t）：**

1. **教学正对照。** 四条原 B 边在某个 ≤ 256 的检查点进入 K_t(0.8)。
2. **死亡。** 对 Θ 中每个 θ，四条原 B 边在检查点 352 都不在 K_t(θ) 中；在 ≥5/7 阈值上，K_B 中 B 三角形 H₁ 类的消失发生在 (288, 352] 内的某个转移，分类为 `edge_loss`。
3. **替换出生。** 四条替换边在某个 ≤ 416 的检查点进入 K_t(0.8)；在 ≥5/7 阈值上，K_B 在 (288, 416] 内有一个转移被分类为 `h1_increase`。
4. **恢复。** 四条替换边在检查点 544 不在 K_t(0.6) 中，因而在所有阈值下都不在；四条原 B 边在检查点 608 在 K_t(0.8) 中。
5. **zigzag 必要性。** 在 ≥5/7 阈值上同时满足以下两条：
   - K_t(θ) ∩ K_B 的 H₁ 并集桥接 zigzag 条形码中，有三条两两不相交的区间，分别与检查点窗 [256, 288]、[416, 480]、[608, 768] 相交；
   - 对同一序列做并集单调化（K̃_t = ∪_{s≤t} K_s ∩ K_B）后的普通持续同调里，在 ≤ 288 出生的 H₁ 类存活到最后一个检查点。
6. **机制区分（本轮由报告项升为判据）。** 在 ≥5/7 阈值上：
   - K_C 中 C 三角形的 H₁ 类在 (128, 384] 内的某个转移因 `clean_fill` 消失（只加入 2-胞腔 fC123，没有移除 0/1-胞腔）；
   - 在 (352, 480] 内重新张开（`h1_increase`）；
   - 在 (544, 672] 内再次因 `clean_fill` 消失；
   - 同一臂中，B 三角形的消失是 `edge_loss`（判据 2）。

   这是论文第 7 页"删除关键路径造成的 H₁ 死亡"与"附加二维胞腔造成的 H₁ 死亡"在 Betti 数上相同、在更新机制上不同的实例。
7. **安慰剂。** A2B2、C2B4 在任何阈值、任何检查点都不进入。

**报告项（不计入成败）：**
- R1：潜在胞腔（A1A3、B2B4、A3B1、B4C1 及潜在面）的进入情况；
- R2：交集桥接条形码（敏感性分析）；
- R3：迁移窗口演示。H₀ 合并（A、C 两个分量经教学边 C4A1 连通，C4A1 于 256 引入）与未训练的 4 步迁移链 C3→C4→A1→A2 的准确率跃迁，是否落在同一个 64 步窗口，且该窗口的跃迁大于其他所有 64 步窗口。这只是演示定义 3.3 (iii) 的计算流程；事件由教学引起，不作涌现主张。

**成功定义：**
- **确认成功**：判据 1–7 在 ≥5/6 个臂中稳健成立（点估计成立且每条判据 s_c ≥ 0.95），并且 S3 在 ≥5/6 个臂中 p ≤ 0.01。
- **部分成立**：上述条件只在 3–4 个臂中满足。
- **失败**：满足的臂 ≤ 2。

三种结果都如实报告，不调参重跑。

## 4. 继续预训练时间拉伸臂（RCN12_FORGET3_X2，世界 635、636 × 种子 1）

**设计来源。** 开发臂 world633_S1_raw 在继续预训练设置下复现了同样的事件顺序，但学得更慢：原 B 边到 288 步退出训练流时还没达到 0.8。因此本臂把 FORGET3 的全部课程时间乘以 2：1536 步，B 边在 576–960 退出，fC123 在 704–1088 退出，其余同理。每 32 步评测一次，检查点数与 SFT 臂相同（49 个）。码本和探针与同号 FORGET3 世界完全相同，PROBES 哈希一致。

**设置。**
- 基座：Qwen2.5-1.5B（非 Instruct）+ LoRA r16/α32。
- 训练文档 `{prompt}\n{gold}\n<eos>`，在全部 token 上计损失。
- 探针前置同类 3-shot 示范，截断到第一个换行。

**判据。** 判据 1–7 与 §3 相同，所有时间窗乘以 2：
1. ≤ 512；
2. 在 704 不在任何 K_t(θ) 中，消失发生在 (576, 704]；
3. ≤ 832，(576, 832]；
4. 替换边在 1088 不在 K_t(0.6) 中，原边在 1216 在 K_t(0.8) 中；
5. 检查点窗 [512, 576]、[832, 960]、[1216, 1536]，单调化条件为"≤ 576 出生的类存活到末尾"；
6. 窗口 (256, 768]、(704, 960]、(1088, 1344]；
7. 同 §3。

**解析率规则**（同第一次确认判据 8）：若最后一个检查点的边、路线、联合探针的 valid_format < 0.9，该臂只报告"基座 few-shot 测量接口不足"，不参与判定。

**结论口径：**
- 2/2 臂判据 1–5、7 稳健成立，并且 S3 p ≤ 0.01 →"继续预训练下复现（时间尺度 ×2）"；
