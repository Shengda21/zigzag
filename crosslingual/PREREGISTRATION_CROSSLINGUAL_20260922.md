# 跨语言桥接实验预注册（世界 501/502）

状态：本地准备完成、未训练。开 GPU 前只允许修正明显的程序错误；本文件中的阈值、窗口、零模型、判据不再更改。

## 1. 问题与假设

设想：训练数据 = 多语言普通知识 + 仅英文的专业知识；用中文、俄文等提问专业知识时，能否观察到论文意义上的“涌现”，即拓扑上的分支/结构变化。

按论文定义 3.3 的三层判据，本实验检验：

| 假设 | 内容 | 判定依据 |
| --- | --- | --- |
| H0 | 跨语言迁移只是逐边渗透：中文专业胞腔各自缓慢通过阈值，没有超过零模型的同步结构事件 | 同步统计量不超过置换零模型 |
| H1 | 候选拓扑涌现：中文专业胞腔在一个检查点区间内同步进入复形，跨阈值网格、跨提示改写、跨种子复现，显著超过零模型 | §5 同步定义 + §6 零模型 |
| H2 | 候选能力涌现：H1 成立，且未参与建复形的独立迁移语言（俄文、日文）在预定窗口内同步改善，解释力超过简单基线 | §7 |
| H_M | 假设：多语言普通知识（MULTI）比单语普通知识（MONO）使桥接更早、更同步 | MULTI 与 MONO 的事件时刻与同步统计量对比 |

“所有涌现都属于这两类”不可由有限实验证明；本实验只回答“观察到的事件能否被分层归类”。

## 2. 为什么专业层用合成理论而不是真实的高阶范畴论

Qwen2.5-1.5B 的预训练语料里已有多语言的范畴论内容；论文要求检查点 0 的原子探针，若中文专业顶点在 t=0 已存在则无分支可合并，实验作废。合成码本（F/D/P/R 四个符号空间、五条映射、两个交换三角形）保证先验为零，答案是语言无关的符号串，可精确匹配评分，且与阶段 A/B 的评分器完全一致。真实理论的“改名版”作为后续扩展，本次不做。

普通层允许模型已经会：它的作用是提供真实内容的多语言指令跟随。

## 3. 数据与条件（已生成、已审计）

每世界：
- 专业层 `SPEC_TRAIN`：仅英文（模板 0/1/2 训练，模板 3 留出改写），每步 32 条 = 顶点读出 4 + 原子边 16 + 联合 fA/fB 6 + 修复 6；512 步。根：训练根 960 对，结构根 32 对，独立根 32 对，探针各取前 16 对。
- 格式复制 `FMT_TRAIN`：en/zh/ru 三语，每步 16 条，两条件共享。它保证中文/俄文的槽位格式在两条件下都被教过，从而 MULTI–MONO 的差异只来自普通知识的语言，不来自格式。
- 普通层 `GEN_MULTI` / `GEN_MONO`：Belebele（800 训练题）与 XQuAD（1058 训练题，上下文按答案位置截窗）交替；MULTI 逐条按 en/zh/ru 轮换，MONO 同一题目全部英文；两者逐条提示 token 数配平（填充 token），题目顺序相同。每步 16 条。
- 探针 `PROBES`（永不训练）：专业任务在 en（3 模板）/zh/ru/ja（各 2 模板）上，同一批 16 个结构根、同一 gold；修复任务 16 个独立根；普通层留出题 en/zh/ru 各 64。共 2448 条/世界。
- 条件：MULTI、MONO；种子 1、2；每步槽位顺序、专业与格式记录在同种子下两条件完全一致（`PAIRING.json` 哈希可核）。
- 检查点：每 16 步评测全部探针并保存 adapter；512 步共 33 个检查点。

审计：`crosslingual/data/CROSSLINGUAL_CPU_AUDIT.json`（哈希、计数、语言分布、留出根/题不泄漏、评分器与 gold 一致、chat 模板下最长 665 token）。

## 4. 预注册复形 K* = G × I

G 为论文中的 11 胞腔理论图：顶点 vF vD vP vR，边 eFD eDP eFP eFR eRP，面 fA=(F,D,P)、fB=(F,P,R)。I 为语言区间 [en, zh]。乘积复形 33 个胞腔：

| 胞腔 | 维 | 可靠性分数 m_t(σ) |
| --- | --- | --- |
| σ@en, σ@zh（σ∈G） | dim σ | 该语言探针上该任务的严格正确率；面 = min(替换/不替换) |
| vX@I（4 条桥边） | 1 | 同一题在 en 与 zh 下**都**正确的比例 |
| eXY@I（5 个方块） | 2 | 同上，对该边任务 |
| fA@I, fB@I（2 个 3-胞腔） | 3 | 同上，对该面任务 |

“都正确”保证 m(桥) ≤ min(两端)，与闭包取 min 的规则一致。K_t(θ) 按式 (3.7) 取闭包。

俄文与日文**不进入 K***，只作独立迁移任务；英文模板 3 只作改写稳健性检验，不进入主复形分数（主分数用模板 0/1 的均值；按单模板分别重算条形码作为稳健性报告）。

预期签名（非结论，已用合成场景在 `test_zz_analyze.py` 中验证其同调事实）：

- **主复形（乘积复形）**：中文顶点读出与桥边 vX@I 很早通过，β0=1。若某条中文边 eXY@zh 与其方块 eXY@I **同时**通过（中文在与英文相同的题上答对），中文副本是可缩地贴到英文副本上的：中文三角形通过三个方块与已填的英文三角形同调，**Betti 数不变**。因此“干净的跨语言桥接”在主复形上不产生同调事件，只在胞腔进入统计量 E_t（§5）上可见——这正是论文“知识量增加与拓扑组织改变是不同量”的情形。会产生同调事件的是：中文边通过但方块未通过（中文答对的题与英文不一致）→ 方块环张开，β1 +1，方块随后通过 → clean_fill；中文面 fA@zh 通过而 fA@I 未通过 → β2 +1；任何胞腔掉出 → edge_loss。
- **去桥子复形 G_en ⊔ G_zh（次级读数，分析脚本同时输出）**：中文顶点作为孤立点出生（β0 上升），中文边把它们合并（H0 `merge` 事件），五条中文边齐后两个中文三角形张开（β1 +2），中文面 fA@zh、fB@zh 通过后填掉（clean_fill）。“连通分支”读数对应这里。
- 两种读数都报告；候选拓扑涌现的主判据用主复形上的置换零模型（§6），“同步 vs 逐边渗透”用 E_t（§5）。

## 5. 同步的操作定义（可证伪）

- 阈值网格 Θ = {0.60, 0.65, …, 0.90}（7 点），检查点间隔 16 步，时间容差 δ_t = 16 步（相邻一个区间）。
- 对每个 (世界, 臂, 种子, θ)，令 E_t = 在检查点 t 进入 K_t(θ) 的 zh 侧胞腔数（5 条 eXY@zh + 5 个 eXY@I，共 10）。
- **同步事件**：存在 t 使 E_t ≥ 6（十个中过半）且该 t 在 ≥ 5/7 个阈值上出现（允许 ±1 个检查点），并在两个种子中都出现（允许 ±1 个检查点）。
- **逐边渗透**：不满足上式，且 zh 侧胞腔进入时刻的极差 ≥ 4 个检查点（64 步）。
- 二者都不满足 → “不可判定”，如实报告。

## 6. 零模型与多重比较

用 `cw_zigzag.permutation_null`：在每个胞腔的分数时间序列上随机交换相邻检查点 (t, t+1)（保留边际），B = 1000，统计量 T_t = (1/|Θ|) Σ_θ E_{1,t,θ}（H1 区间端点数，论文 §3.1 程序），p = (1+#{T^{(b)} ≥ T})/(B+1)，Bonferroni 校正 N_test = |D|·T（D = {0,1}，T = 32 个区间）。独立单位 = 世界 × 种子（开发世界只有 2×2，因此本轮结果一律标注“开发描述，无确认性 p 值”）。

## 7. 独立迁移与基线

- 迁移量：ru、ja 专业探针的原子边正确率、联合任务正确率（各自语言）。
- 事件窗口：zh 同步事件检查点 ±16 步；对照窗口：同臂中等长的非事件窗口（预先取事件前 64 步之外的所有区间）。
- 比较：窗口内 ru/ja 分数增量 vs 对照窗口；解释变量基线：min_e m_t(e@zh)、已通过面数、全体胞腔平均分及其斜率；报告嵌套模型的增量解释力。只有条形码事件类型在控制基线后仍有增量，才报告“候选能力涌现”。

## 8. 臂内门槛（只报告，不阻断）

- 英文专业层学会：512 步时英文模板 3 的五条边 ≥ 0.9；否则该臂标为“专业层未学会”，其跨语言结果不解释。
- 每语言解析率单独报告；zh/ru/ja 解析率 < 0.95 时把该语言的顶点/边结果标为“测量接口受限”。
