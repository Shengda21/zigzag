# 单张 RTX 3090：行为能力复形与 zigzag 持续同调实验协议
版本：v1（建议方案；正式实验前锁定）
状态：数据生成、判分器与小规模代数检查已在 CPU 环境执行。没有运行语言模型训练、推理或正式统计检验。

## 1. 研究范围与待检验问题
依据论文《大模型能力空间的几何实现与 Zigzag 持续同调》§3.1–3.2、定义3.3、式(3.6)–(3.10)设计。
这是新增实验建议，不是原稿已有实证，也不以单个同调类天然等同于语义能力为前提。

核心问题：
1. 固定行为编码后，小模型的训练状态是否实测为非嵌套？
2. zigzag 是否区分 Betti 数相同但延续关系不同的情形？
3. 同样的 H1 消失，是否可以结合胞腔更新记录区分删边与填面？
4. 拓扑变化是否稳健，并与未用于建复形的行为任务同步？

不把“出现一张好看的条形码”“H1上升/下降”或“连续微调必然遗忘”作为成功前提。
原始分数与附着关系包含计算拓扑摘要所需的全部信息；不声称拓扑创造额外信息。

## 2. 固定的11胞腔环境
顶点编号：F=0（分数），D=1（有限小数），P=2（百分数），R=3（每b个人中有a个人符合条件）。
顶点语义限定为本表示的解析，而非完整理解该知识领域。
- 顶点：vF,vD,vP,vR。
- 边：eFD,eDP,eFP,eFR,eRP。
- 二维胞腔：fA=(F,D,P)，fB=(F,P,R)。
所有面必须独立通过探针；禁止自动补齐团复形。
主分析系数域F2、同调维数H1；H0描述性报告。

方向仅存于语义：FD为F->D，DP为D->P，FP为F->P，FR为F->R，RP为R->P。
普通单纯/CW同调不区分推理方向，不把有向训练的结果说成方向敏感拓扑。

### 操作性任务
vF解析分子和分母；vD读取整数与小数部分；vP读取百分号前数字；vR提取符合人数与总人数。
每条边测试指定转换。
fA要求联合输出：直接百分数 | 中间小数 | 经小数路线的百分数。
fB要求联合输出：直接百分数 | 中间符合人数 | 中间总人数 | 经比例描述路线的百分数。
例如7/20，fA标准输出35%|0.35|35%；fB标准输出35%|7|20|35%。

面分数要求每个中间/终点值均正确，并按精确有理数判定，不能因两个终点同错但一致而通过。
这是“联合路径输出正确性”的行为测量，不证明模型内部实际执行了两条推理路径。
面探针是独立的联合请求，不由三条边的平均得分相乘生成。
补充的长度对照同样要求三项输出，但三个输入是互不关联的数值。
同一阈值下多步骤任务可能因联合成功条件而更难，因此不得把所有缺面都归因为高阶机制缺失。

## 3. 数据划分、题目依赖与评分
所有潜在值为m/10000（m=1..9999），用Fraction约分后作为潜在题目键。
互不重叠的根数值池：训练6000、开发512、结构测量256、独立验证预留512、长度对照384。
先划分潜在有理数，再生成各种表示与模板。不按表面字符串随机划分，避免等价表示泄漏。
这些值来自同一有限网格，留出数值不等于外推到新分母族或更高精度；不要称为强OOD证据。

训练模板0、2；正式测量模板0、1，其中模板1的指令改写不参与训练。
指令改写较轻，支持范围是这些预注册模板，不能泛化为任意提示鲁棒性。

结构测量：256个潜在题目 x 11胞腔 x 2模板 = 5632提示/检查点。
独立验证：128道跨表示大小比较 + 128道定位并修复首个错误步骤，各2模板，共512提示。
长度对照：每个面64个独立三任务束，共128题，各2模板，共256提示。
合计6400提示/检查点。独立验证与对照不参与建复形、选阈值或挑检查点。

评分：优先语法解析+Fraction/Decimal精确数值比较；格式错误记0，另列格式有效率。
不使用浮点误差阈值、不让另一个大模型充当裁判、不进行多次采样择优。
面中间的比例人数允许等价正整数比；百分数必须有百分号；解析顶点要求读出原字段。

同一结构潜在题目在所有胞腔、模板、检查点上的输出是一个关联簇。
bootstrap时整簇重采样，不能把同题的两个模板当两个独立题目。
跨表示比较/长度对照各自按完整题目束重采样。

## 4. 训练处理与控制
主模型Qwen/Qwen2.5-0.5B-Instruct，LoRA r16、alpha32、dropout0.05；不量化。
目标层q/k/v/o_proj与gate/up/down_proj。只更新一个持续存在的adapter，阶段之间不重置adapter或优化器。

A域：F,D,P三个解析、FD/DP/FP三条转换、fA联合路径。
B域：F,P,R三个解析、FR/RP/FP三条转换、fB联合路径。
两域有共享能力且规则相容，不改变同一题的正确答案来强行制造遗忘。

每阶段7680个训练呈现：原子20%、边60%、面20%。
有效batch32，每阶段240个优化器更新，三阶段共720更新。
顺序组：A1 -> B -> A2；A1、A2为同一域的不同预生成示例流。
混合组：将同样的23040条示例整体打乱。A:B总呈现比为2:1，而不是1:1。
每个训练种子内，两条件使用相同初始基础权重及相同adapter初始化、优化器和学习率设置。
两组最终总样本多重集、token多重集一致；中途任务暴露不同是顺序处理本身。

正式种子11、22、33，两个条件共6条训练轨迹。
微批4、累积8、总长度上限256、AdamW学习率2e-4、warmup20步后恒定、梯度裁剪1。
仅对assistant回答token计算损失。超长样本需报错并在开发阶段统一修订，不默默截断答案。
BF16是否支持由本机检测；不支持时统一采用FP16+loss scaling，并记录。
启用gradient checkpointing，训练关闭KV cache。完整参数在protocol.yaml中。
OOM时可在正式实验前改为微批2、累积16，保持有效batch32；正式运行中不能偷偷换方法。

每60步保存adapter及所需复现信息：
0,60,120,180,240,300,360,420,480,540,600,660,720。
粗网格先分析0,120,240,360,480,600,720；全13点作为预注册检查点细化。
评估时不更新权重，model.eval()+不采样，max_new_tokens32。
训练断点需保存optimizer、scheduler、随机数和数据游标；其他评测断点可只保存adapter与配置。

## 5. 先开发再锁定
仅用seed0与开发集做可行性检查，例如每阶段60步的小运行；它不进入正式统计。
检查格式、答案token长度、梯度有限性、显存峰值、学习是否发生、任务是否地板/天花板。
不查看正式结构/验证输出、不看条形码挑任务、不选择“最容易遗忘”的种子。
若全部关系从头到尾近乎全对或全错，说明此任务设置缺乏区分度，需在开发阶段修订难度并重新锁定。
正式前记录model commit、软件版本、生成器/数据哈希、阈值、检查点、统计族及任何开发修改。
默认参数是起点，不是已被3090实测验证的最优配置。

## 6. 拓扑与统计
对每个seed、条件、检查点计算各胞腔的题目-模板平均成功率m。
按原稿式(3.7)应用所有闭面的最小值，确保面闭合。
阈值为0.60,0.65,0.70,0.75,0.80,0.85,0.90，禁止事后择阈值。

同时计算并集、交集zigzag；并集H1是预注册主分析，交集是必须报告的敏感性分析。
记录原增广节点索引，并标识checkpoint/bridge。桥节点不是某个真实训练状态。
即便桥的画图横坐标恰好等于保存的加密检查点步数，也不能把二者当同一对象。

记录每次变化的新增/删除胞腔、维数、面自身得分、边界得分、缺失原因。
面自身通过但因边界未通过而缺失，应与面自身不通过分开。
若一次检查点间变化同时删边加面，先报告混合事件，不凭任意微步骤排序认定唯一原因。
11胞腔复形在FP边缺失但外侧四边保留时，仍可有外部四边形H1类；不能把每个H1类强行对应单个面。

原稿E与T作为主端点统计量照算。观察窗口首尾为截尾，不解释为真实出生/死亡。
去除观察边界端点的版本作为预注册敏感性分析，不事后替换主要统计量。
bootstrap2000次，按题目簇同步重采样所有时间、胞腔、模板；每个训练种子单独报告。
三个训练种子不足以精确估计训练随机性的总体分布，题目层置信区间不等于多次训练置信区间。

置换4999次，按原稿在每个题目簇-种子块内同步交换相邻检查点标签，
同次交换作用于所有胞腔和模板，并重新构建完整复形序列与条形码。
它要求相应交换性零假设；不是只“打乱一条已聚合好的Betti曲线”。

主检验族：3种子 x 2条件 x 6粗网格相邻区间 x H1/并集 = 36。
Bonferroni阈值0.05/36；不得只对观察到变化的少数区间做校正。
若也对H0、交集或额外统计量作正式显著性声明，必须预先扩大检验族。
独立迁移同时报告原始分数、预先固定阶段差及成对题目置信区间，不再事后挑显著时刻。

候选事件：至少覆盖7阈值中的5个，含至少3连续阈值；3个训练种子复现；
支持不少于2个真实粗检查点；加密后同类事件在原事件区间中点±60优化步内出现；
超过预注册零模型。独立迁移同步才讨论原稿定义的候选能力涌现。
事件匹配预先固定维数、出生/死亡类型和最短支持，不要求跨阈值条形码逐类同一性。
没有满足全部条件时，降级报告拓扑变化或有限案例，不将其写成普适涌现。

正式大规模分析前建议用固定潜在能力、仅题目应答噪声的模拟做零模型校准，
再做真实能力改变的正对照。误报率应附有限Monte Carlo次数的不确定性。
这项统计校准尚未在本附件中执行，toy_checks.py只验证代数，不替代校准。

## 7. 必须保留的对照
平均正确率；11维原始分数向量；各维胞腔数；Betti曲线；
相邻胞腔集合变化/对称差；历史累计复形；交/并桥接；长度匹配非闭路任务。
可以把面分数与单步可靠性乘积做描述性独立误差参照，但后者不是普遍成立的概率模型。
不能因为面比单步更难，就宣称出现新的推理机制。
没有足够独立轨迹时，不把相邻检查点当独立样本做预测性能的显著性比较。

## 8. CPU代数检查与生产实现
toy_checks.py用显式同调映射检查：
- 同一个环保持：[0,2]；
- 同Betti数但左环换右环：[0,1]和[1,2]；
- 只存在于并集桥的环：[1,1]；
- 填面与删边的不同并集增广区间；
- 11胞腔环境的边界平方为零及四种Betti数检查。
这些是理想化单元测试，不是语言模型测量。

生产zigzag可使用Dionysus的zigzag功能；本附件未提供其生产级封装。
若库将一次集合包含拆为单纯形微更新，加时必须先面后胞腔、删时先胞腔后面；
最终须限制回论文的原始增广节点，不能把任意串行顺序产生的微步骤条形码当实验事件。
真实桥节点上的过渡类仍保留并单列，不混入真实检查点能力。

## 9. 预算与执行记录
6轨迹 x 720优化器步 = 4320步；训练呈现总数138240。
粗网格：6 x 7 x 6400 = 268800次短答案生成（未复用相同初始模型）。
全13点：6 x 13 x 6400 = 499200次；不需重新训练。
bootstrap、阈值扫描、桥接和置换均复用逐题结果，不再调用模型。

尚未实测3090吞吐、实际峰值显存或耗时，不给出GPU小时保证。
先测20个训练步及一个评测小批，记录时间、有效token数、峰值显存和adapter文件大小，
据此决定是否在正式解封前采用128题的预算版；改变后应重写协议及重采样参数。
本文默认正式结构题数仍为256。优先减任务面宽，不优先删去对照与种子。

## 11. 文件与使用
- protocol.yaml：研究配置，非可直接传入Trainer的参数字典。
- make_data.py：标准库数据生成器与score_prediction精确判分。
- data/：已生成数据及manifest/哈希。训练混合参考文件与A1/B/A2是同一多重集，不是额外训练数据。
- toy_checks.py：需要NumPy的透明小规模代数单元测试。
- toy_check_results.json：已执行的代数检查结果。
本包不包含GPU训练驱动、生产级zigzag封装或正式统计执行器。

运行：
python make_data.py --out regenerated_data
python toy_checks.py

在make_data.py中可导入score_prediction(record, prediction)，返回correct与valid_format。
建议逐条缓存：
run_id,condition,seed,optimizer_step,item_id,cell,template,prompt_hash,prediction,correct,valid_format。
辅助连续诊断可加逐答案token负对数似然，但不要把训练loss直接当成功概率用于式(3.7)。
