预设七取五结构事件的七个阈值标记为 [True, True, True, True, False, False, False]，联合事件重抽样支持 0.001。结构优势、强迁移和正向配对优势均未通过；低阶保留及格式门槛通过。每组只有一个训练随机种子，项目重抽样不含训练随机性。

理想的六个干净面在 cycle 组构成双锥，Betti 向量为 (1,1,1)；对照为 (1,0,0)。cycle 组的干净面不覆盖 AB，对照覆盖全部十个算子对。因而该设计没有分离三元拓扑与配对覆盖。实际终点两组 H2 都为零，也没有实现想操纵的拓扑差异。结果不支持这种面排布训练技巧，不能解释为对原理论的反证。
