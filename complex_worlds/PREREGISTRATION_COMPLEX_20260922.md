# 表示转换网络世界（RCN12，世界 601–604）预注册

状态：本地生成、审计、干跑完成；未训练。开机前只允许修程序错误，本文件的判据不再更改。

## 1. 目的

为“候选拓扑涌现”提供一个**有真值、有对照、事件足够多**的评测集：复形上每个可能事件的最早可能时刻已知；有永不可能通过的安慰剂胞腔；有既可能出现、又没被教过的潜在胞腔。涌现评测 = 潜在胞腔的出生表及其引起的 Betti 变化，而不是任何一条分数曲线。

## 2. 复形（`specs/RCN12.json`，生成器 `code/spec_world.py`）

12 个表示类型分三个域：A1–A4、B1–B4、C1–C4。每个类型是底层 0–31 索引的一种编码（前缀 + 三位数字）；边 X→Y 是索引上的置换。

| 类别 | 胞腔 | 说明 |
| --- | --- | --- |
| 教过的码本边（13） | A1A2 A2A3 A1A4 A4A3 B1B2 B2B3 B1B3* B3B4 C1C2 C2C3 C1C3 C3C4，及规则边 C4A1 | 按课程表进入训练流；B1B3* 是扭转边（与 B1→B2→B3 不一致） |
| 潜在边（4） | A1A3、B2B4（组合可推出）；A3B1、B4C1（“保留数字换前缀”规则，只在 C4A1 上教过） | 只探针，永不训练 |
| 安慰剂边（2） | A2B2、C2B4（随机置换，跨域，不可推出） | 只探针；任何出生都是假阳性 |
| 教过的面 | fC123（一致，联合任务自 128 步训练）；fB123（不一致，联合任务自 128 步训练、标志恒为 0，**不是** 2-胞腔） | |
| 潜在面（3） | fA123、fA143、fB234 | 只探针 |
| 永久洞（2） | 扭转三角形 B1B2B3；跨域 11 边大环 A3B1…C4A1…A2A3（不声明 2-胞腔） | 负对照：不得被填 |

课程：0 步起 8 条边；64 步加入 A4A3、B1B3、B3B4、C3C4；128 步联合任务；192 步修复任务；256 步规则边 C4A1。每步 64 条 = 顶点读出 8 + 边 32 + 联合 12 + 修复 4 + 格式复制 8（联合/修复未引入时由边补齐）。

真值（`GROUND_TRUTH.json`，由 `cw_zigzag` 计算并与手算断言一致）：

| 阶段 | β₀ | β₁ |
| --- | --- | --- |
| < 64 步（教过的） | 5 | 1 |
| < 128 | 3 | 3 |
| < 256（fC123 填） | 3 | 2 |
| 全部教过（C4A1 合并 A、C） | 2 | 2 |
| + A3B1 | 1 | 2 |
| + B4C1（大环闭合） | 1 | 3 |
| 全部教过 + 全部潜在 | 1 | 2 |

潜在胞腔最早可能时刻：A1A3、fA123 = 0；B2B4、fA143、fB234 = 64；A3B1、B4C1 = 256。

## 3. 探针与胞腔分数

- 顶点：16 个结构根 × 模板 0/1；边：32 根 × 模板 0/1/3；面：32 根 × 替换/不替换 × 模板 0/3；每世界 3072 条，每 16 步全部评测。
- m_t(顶点/边) = 主模板（0/1）严格正确率；m_t(面) = min(替换, 不替换) 的联合任务严格正确率（四字段含标志）；模板 3 单独作为改写稳健性重算。
- 阈值网格 Θ = {0.60,…,0.90}，闭包取 min，每 16 步一个检查点，时间容差 16 步。
- 迁移任务（不进复形）：四条三步链（其中 A1→A2→A3→B1 需要潜在桥 A3B1，C3→C4→A1→A2 需要教过的规则边）、fC123 的修复任务、模板 3。

## 4. 判据

- **正对照**：教过的边/面在引入后 ≤ 64 步内进入 K_t(θ)（θ ≤ 0.8）；否则该臂标为“教学未完成”。
- **安慰剂**：A2B2、C2B4 在任何阈值、任何检查点都不得进入；进入即报告为测量假阳性并作废该臂的涌现判定。
- **候选事件**（每个潜在胞腔单独判）：进入时刻 ≥ 最早可能时刻；连续 ≥ 2 个检查点保持；≥ 5/7 阈值上出现（±1 检查点）；两个种子都出现（±1 检查点）；置换零模型（`cw_zigzag.permutation_null`，B=1000，Bonferroni）在该转移显著。满足者按拓扑分类：
  - A1A3 / B2B4 出生：新环（H₁ +1，“第二条路”），随后 fA123/fA143/fB234 若出生 → clean_fill；
  - A3B1 出生：H₀ 合并（2→1）；B4C1 出生：大环闭合（H₁ +1，无 2-胞腔可填）；
  - 任何教过胞腔掉出：edge_loss（遗忘），单独统计。
- **候选能力涌现**：候选事件窗口（事件检查点 ±16 步）内，链任务/修复/模板 3 的增量超过对照窗口，且在控制 min_e m_t(e)、已通过面数、平均分之后仍有增量。
- **失败结论也保留**：若组合边从不出生（组合鸿沟），报告为“复形只随教学增长、无潜在事件”，这本身是对“涌现”定义的一个否定性数据点。

## 5. 独立单位、规模、预算

世界 = 不同数字表与置换（同一图）；4 个世界 × 2 种子。每臂：512 步（约 30 min）+ 33 次评测 × 3072 行（约 40 min）≈ 70 min。队列先跑四个世界的种子 1（≈ 4.7 h，≈ 47 元），再跑种子 2。

## 6. 局限

同一张图的四个世界只是码本不同，不是图结构的重复；组合潜在边可能永不出现（已知的组合鸿沟）；规则边的泛化可能过快以致在 256 步后的第一个检查点就出现（那时事件仍可判，但时间分辨率只有 16 步）。
