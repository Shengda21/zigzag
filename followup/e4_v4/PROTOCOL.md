# E4-v4 protocol: explicit operand correlation

Fixed before any v4 model outcome. Local pilot data are generated only for CPU audit. The independent causal-design critique supported the explicit-operand alignment design described here. No v4 GPU outcome was available when this protocol and its gates were fixed.

The v3 Mode J/E label covaries perfectly with arm on condition rows and external uses J. V3 is feasibility evidence only and must not advance to confirmation.

V4 removes Mode J/E and all arbitrary arm labels from model-visible text. Both arms receive the same neutral three-slot mapping instruction framework. All condition operands are explicitly supplied. Joint-arm slot2 input is the correct slot1 endpoint; edge-arm slot2 input is an independently chosen root. The targets follow the same declared maps in both arms. Hence the intervention is dependency-consistent versus independent operand co-occurrence, not a requirement to compute an unprovided intermediate during training. This is a changed estimand, and must never be described as isolating internally executed composition. Direct endpoint shortcuts remain.

All training, diagnostic and external prompts use a common slot-program grammar. Slots name a map and an operand. Operands are explicit representation-coded values or an earlier slot reference. Sequential external AB,BC,CD references earlier outputs. The shared instruction legend explains both operand types in both arms. No arbitrary J/E marker, arm name or treatment tag is exposed. External semantic dependency references are task specification rather than an arm label. Shared two-hop reference rehearsal supports output-N syntax in both arms; a held-out diagnostic control tests that support. External length-three dependency remains held out.

Both arms retain 32768 rows,512 updates,batch64,75% condition and25% common rehearsal. They teach AB->BC at slot2 and BC->CD at slot3 separately. No row joins these into a depth2 chain; a rule list AB/BC/CD in type B is not itself a three-hop dependency. No reference row has a same-root full B/C/D answer bundle. This common support changes the intervention to additional coherent explicit-operand exposure above a shared two-hop reference curriculum; differential composition exposure is not the treatment.
