状态：2026-09-24 写成，时间早于任何 Pythia 轨迹数据被读取。此前唯一运行的是最终检查点 step143000 的能力检查，用来决定模型规模（规则见 §2），写本文件时其结果尚未读取。本线是描述性的外部效度检验，没有课程真值，不作涌现主张。

## 1. 问题

论文 §3.2 的前提是：真实训练中相邻检查点的能力复形可能互不包含，即 K_t ⊄ K_{t+1}，因而需要 zigzag。原文只引用了微调中的灾难性遗忘 [6]。本线检验**预训练本身**是否也出现稳健的非嵌套。具体做法是：在同一模型家族公开的预训练检查点上做纯推理（不做任何梯度更新），测量 3 个域的原子能力复形。

## 4. 预注册量与假设

**P1 稳健退出（主假设 H_P1）。** 对胞腔 c 和阈值 θ，称检查点 t 处发生一次"退出"，条件是：
- c ∈ K_t(θ)；
- c ∉ K_{t+1}(θ) 且 c ∉ K_{t+2}(θ)，即至少连续缺席两个检查点，排除单点闪烁。

这次退出**稳健**的条件是：在 ≥ 95% 的 bootstrap 重复里，c 在 [t−1, t+1] 内的某个检查点发生了同样定义的退出。

H_P1 成立的条件：在 ≥ 5/7 个阈值上，至少有一次稳健退出。
- 成立：预训练轨迹在这个能力复形上确实非嵌套，论文 §3.2 的前提在预训练中得到支持；
- 不成立：如实报告"在该复形与该检查点粒度下，预训练轨迹近似嵌套"，并讨论粒度与探针规模的限制。

**P2 zigzag 与单调化的对照（描述）。** 在每个阈值上报告：
- H₀、H₁ 并集桥接 zigzag 条形码中，在最后一个检查点之前结束的有限条数；
- 对同一序列做并集单调化后，普通持续同调中的相应条数；
- 两者之差，即单调化"永久保留"的已遗忘结构。

**P3 时间组织（S3）。** 报告 p 值；p ≤ 0.01 记为"拓扑轨迹在预训练时间上有组织"。

**P4 事件机制（描述）。** 对稳健的 H₁ 减少事件，按 `clean_fill`（加入面）和 `edge_loss`（移除边）分类计数，对应论文第 7 页"两种 H₁ 死亡"。对稳健的 H₀ 合并事件，列出引起合并的边。

## 5. 解释的边界

- 只有一个模型、一次训练，没有跨种子复现，结论限于"存在性"与描述；
- 任务的 gold 来自确定性 oracle，但 few-shot 模板和解码设置会影响分数水平；因此只把跨阈值、bootstrap 都稳健的事件作为结论；
- 不作涌现主张：本线没有课程真值，无法区分"习得"与"模板敏感性变化"，只回答"是否非嵌套"。
