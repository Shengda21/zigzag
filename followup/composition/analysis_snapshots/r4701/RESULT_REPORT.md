# R4701：单面定向遗忘闸门

**预设联合闸门未通过：0/10，要求至少 8/10。十次操纵检验均未通过。**

每个条件从同一个成功适配器独立开始。目标面后缀置换，其他九面继续干净监督；低阶锚点保留。先在 32、64、96、128 步诊断，只有目标面低于 .60、其他九面均不低于 .80，且低阶与格式保留时，才能选择最早的合格检查点。没有合格检查点的条件仅在 128 步做描述性四算子评测。阈值和对比没有随结果调整。

四算子组按是否包含被指定破坏面划分。由于操纵失败，不能把它们直接称作“边界完整”和“边界不完整”：部分不含目标面的子集也失去了其他面。正的组间差异不能替代预设闸门。实际边界最低分和完整子集清单另存于 AGGREGATE.json，仅作事后诊断。

该结果否定当前监督置换协议能隔离单面能力的假设，尚不能否定一般闭合规则。按当前协议直接推进两面交换实验没有依据。没有启动更多面壳课程。

原始协议见 PROTOCOL.md；完整十面溢出图见 gate_matrix.pdf。统计规则在模型查询前固定；聚合代码实现于已检查前三个结果之后，这一时间关系保留在结果元数据中。
