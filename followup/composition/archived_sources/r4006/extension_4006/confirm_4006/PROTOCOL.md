queried. Every root and intermediate state is disjoint from the r4004
source and repair data, both earlier development/confirmation probes,
all earlier three-operator training banks, and the new length-nine/ten

additional updates passing every r4006 development gate on the older

binary prefix scores (.95/.85), format+EOS (.98), and robust new H2

bank. Report all failures; this confirmation cannot change the failed
