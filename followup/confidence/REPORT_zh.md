# 同时置信复形与有限样本下证书：已执行报告

本补充只写入本目录；未改正文、既有理论、原始评估或实验预注册。它是标准置信区间与像/余核秩的计算协议，不主张新的拓扑定理或统计理论。

**结论。** 在全部六个确认臂、原 B 子复形、全部 49 个检查点上做联合 95% 的设计匹配分析，原阈值网格 0.60–0.90 的所有 H1 像秩和余核下证书均为零。主要瓶颈是每个顶点只有 16 个不同根，不能把两种改写当成 32 个独立观测。在同一个同时置信事件内，探索阈值 0.50 可得到真实的、条件有限总体意义下的正证书；压缩为单一全局误差半径后正检查点减少，bridge-only 证书全部消失。这说明坐标置信包络有用，但不能把原来的 0.8 阈值 bootstrap 结果升级成覆盖保证。

## 1. 先核查实际抽样设计

`complex_worlds/code/spec_world.py` 把 32²=1024 个长度二根随机打乱，前 960 个供训练，接下来 32 个供结构探针，其余 32 个供独立 transfer/repair。结构顶点只取该顺序的前 16 个；边和面取全部 32 个。顶点、边的 main template 是 0 和 1；面实际只有 template 0。

因此，**现有结构根不是 iid with replacement**。但条件于生成的代码表、960 根训练集、训练随机性和固定训练轨迹，结构根是剩余 64 根的简单无放回样本，单根准确率可做有限总体精确推断。无放回本身不是无效的理由。

联合面 keep 提问只依赖本根；override 提问则取 `other = st[(j+1)%32]`。后者在 32 根环上共享输入，不是 32 个独立 pair。它的总体目标是剩余 64 根中**不同有序 pair** 的均匀平均准确率；keep 和单根任务的目标是这 64 根的均匀平均。每个面仍按原协议取 keep/override 两个总体准确率的较小值，未删去 fB123 或 fB234。

训练代码核查支持上述条件化：`run_complex.py`、`stage_ab/code/zz_train.py` 的当前内容与六臂 manifest 中记录的训练代码一致；训练固定 768 步，学习率只依赖步数，评估结果只写出且不参与训练、选最优模型或早停。评估前保存并在评估后恢复随机数状态。六臂均有原始固定网格的 49 个评估。可存在的人工运行选择不能由代码证明排除，因此覆盖声明仍明确条件于预先固定的这六臂及完整网格，不推广到自适应挑选的世界或任意新代码表。

现有 independent32 只有 chain/repair，没有同一结构任务、同一 template 的剩余 32 根输出，不能伪装成 64 根普查。

`design_audit.json` 已保存六臂逐项检查：代码与 manifest 一致、三段根数为 960/32/32、固定 49 点完整；每臂实际归档的 **15680** 个 override joint 输出的 `other` 均与 manifest 中的 32 根循环对应，未只依据当前生成器猜测旧数据的配对方式。

## 2. 同时置信盒：全 family 一次保护

固定原预注册 B 子复形的 15 个胞腔，包含面边界；保护六臂的每个检查点、每个原始 component、每个实际使用的 template。family 总计 **m=8232** 个标量 Bernoulli-template 坐标。所有区间分配相同两侧尾概率

\[
q=0.05/(2m).
\]

跨 template、时间、胞腔和训练 seed 均可任意相关；只使用并合界。未根据出现事件的局部时间段或局部胞腔重分配 family。下列所有阈值和窗口检查都在同一个置信盒上完成，不增加 family 大小。阈值 0.4、0.5 是事后诊断，不是原预注册确认结论。

**单根坐标。** 对 n=16 或 32、总体大小 N=64，用超几何分布反演未知总体成功数 K。观察 x 个成功后保留满足

\[
\Pr_K(X\ge x)\ge q,\qquad \Pr_K(X\le x)\ge q
\]

的 K，取最小/最大 K/64。对每个真 K，被任一尾排除的概率至多 2q。代码还在 K=0,…,64 上逐一枚举覆盖概率。

**override 环坐标。** 对有序 n 根样本的环平均，每次置换两个总体标签至多改变四个项，因此函数变化至多 4/n。顺序暴露前 n 个排列位置，用交换剩余标签的耦合可知每步 Doob 鞅差的条件取值范围至多 4/n。条件 Hoeffding 引理及 Chernoff 界给出

\[
\Pr\{|\hat p-p|>e\}\le2\exp[-ne^2/8],\qquad
e=4\sqrt{\log(2m/0.05)/(2n)}.
\]

本数据该 e 大于 1，故此类区间退化为 [0,1]。这是诚实的保守界；没有以 item bootstrap 分位数替换覆盖保证。面先对改写区间取平均，再按两个 variant 取最小端点，保持原分数定义。

对比的全局半径不是另一个更弱统计假设：它就是把**同一组**区间压缩为

\[
\epsilon=\max_{\sigma,t}\max(\hat s_t(\sigma)-\ell_t(\sigma),u_t(\sigma)-\hat s_t(\sigma)),
\]

这里先完成 template 平均、variant 最小值，得到实际胞腔 score 的上下端点 ell/u，**随后**才计算 scalar 半径；再对所有胞腔用 `[score-epsilon,score+epsilon]∩[0,1]`。坐标包络与其 scalar 压缩有相同联合覆盖事件；均未事后缩小 family。本数据实际胞腔 epsilon 为 .500、.500、.4921875、.4921875、.500、.484375。合并前 component 的最大半径为 1，但它只是额外诊断，不是主要比较基线。

## 3. 为什么这些下证书有效

令 L_t(a)、U_t(a) 分别由胞腔分数区间的下/上端点按原 face-min 闭包构成。联合事件上，对所有阈值都有

\[
L_t(a)\subseteq K_t(a)\subseteq U_t(a).
\]

设 a=theta+delta、b=theta-delta。桥目标 W 是两个相邻端点的 union；令

\[
I_L=\operatorname{im}[H_k(L_W(a))\to H_k(U_W(b))],
\quad J_U=\sum_{s\in S}\operatorname{im}[H_k(U_s(b))\to H_k(U_W(b))].
\]

报告

\[
\underline\kappa_S=\dim(I_L+J_U)-\dim J_U.
\]

证明不依赖 Betti 数单调性。真实窗口余核像秩是从 H(K_W(a)) 映入 H(K_W(b))、再模掉真实 source 像所得之秩。L_W(a) 的像先经过真实窗口，再映入 U_W(b)；真实 source 像在该映射下落入 J_U。故从真实窗口余核的一个子空间到上述下证书空间存在满射，得到 `lower kappa <= true kappa`。同理，`rank[H(L_t(a))→H(U_t(b))]` 不超过真实对角像秩。union/intersection 都保包含关系，可延展到其他固定模式。

S 分别取前端点、后端点或两端点时，得到三个有效余核秩下界。**不能把两个下界之差当成 birth/death 的下界。** 本代码没有报告这种差。

点态 Betti sandwich 不成立：三角形边界包含于填充三角形，但 beta1 从 1 变成 0。`dim H(U)/im H(L_sources)` 也不能自动作为真实余核上界，因为进入 U 可能杀死真实类。本补充只报告有证明的下证书，不编造两侧秩界。

## 4. 六臂实测结果

完整 family 下，即使每项都答对，n=16 的单根总体准确率下界为 **34/64=0.53125**，n=32 为 **49/64=0.765625**。所以原网格最小阈值 0.60 已经无法把顶点纳入下复形；下复形不能产生 H1 周期。这里零证书的直接原因可以定位，绝非观察到的拓扑必须为零。

| 确认臂 | theta=.8, delta=0 的正检查点数 | theta=.5, delta=0 的正检查点数 | theta=.5 的 480→496 transition 下界 | theta=.4, delta=.05 的 480→496 transition 下界 |
|---|---:|---:|---:|---:|
| world635 S1 | 0 | 34 | 2 | 2 |
| world635 S2 | 0 | 21 | 2 | 2 |
| world636 S1 | 0 | 30 | 2 | 2 |
| world636 S2 | 0 | 32 | 1 | 3 |
| world637 S1 | 0 | 31 | 1 | 2 |
| world637 S2 | 0 | 26 | 0 | 1 |

原 theta=.60,.65,.70,.75,.80,.85,.90，delta=0,.05,.10 全部为零下证书。在 theta=.5、delta=0，scalar 压缩的正检查点数分别为 24、19、20、21、20、22，均少于坐标方案；scalar 没有 bridge-only 证书（但 world636 S1/S2 各有一个 backward-cokernel 下界1）。在 theta=.4、delta=.05，坐标方案六臂都有 bridge-only H1 transition 下证书，scalar 全部没有；坐标方案每臂 288→304 的 backward-cokernel 下界为 1。较低阈值不是替代原确认阈值的新成功标准；其作用是证明协议不恒等于零，并展示同一置信事件下保留坐标信息的价值。

`real_results.json` 保存完整每检查点像秩与所有正 transition；每臂两个 `.npz` 保存点估计、胞腔及 component-template 的上下包络，可独立复查。

## 5. 已知真值 CPU 模拟

两个场景均有三检查点、三顶点三边及一个三角形面；真正 family 为 42 个 template 坐标，比较始终保护同一个 family。根单位 iid，两个改写完全相同，而且各胞腔/检查点共用每根同一个 uniform 随机变量，刻意保留强相关。CP 只作用在每个独立根的单个 template Bernoulli 上；未把相关改写当额外样本。

clear 场景顶点真准确率 .99，存在边 .95，不存在边 .10，面 .05，前两个检查点为两条不同路径，其 union 形成过渡环，第三检查点形成完整环。null 场景三条边均 .79，目标阈值 .8 下无环。每场景每 n=32,128,512,2048 执行 1000 次，共 **8000 次**。

## 6. 独立验证与下一轮预算

`validation.json`：在最小平行边复形中，对两端点全部 70 个 L⊆K⊆U 嵌套三元组的组合、三个 source 方案，穷举 **14700** 个余核下界不等式；全部通过。对 N=64、n=16/32、全部65个总体成功数 K 枚举超几何精确覆盖；最大非覆盖小于分配的 5e-6。

`verify_independent.py` 不用原 `CW.homology`、`induced` 或 Gaussian rank，以穷举边链、边界链和 XOR 和空间独立重算了全部六臂、两种统计方案、坐标/全局两种表示、全部阈值窗口的 **125064** 个像/余核秩，全部一致。

若下一轮采用 iid 独立根/独立 pair，按同等 m=8232 的 CP family，**全部正确这个最佳情形**要下界达到 .8/.85/.9，至少要 57/79/121 个独立单位。此数不是有功效预算：若真准确率 .95，n=256 的单坐标下界达到 .8/.85/.9 的概率分别为 .99745/.69853/.02625；n=512 则约 1/.99924/.27094。完整事件的功效还取决于全部胞腔、pair 及时间，不能从单坐标功效直接宣称。

另一可行路径是保持有限总体目标，对剩余64根做单根普查，去除这些坐标的抽样不确定性；override 若要相同总体目标则需64×63不同有序 pair 的普查，或明确改为预先固定、独立采样的pair分布。不能把训练中的960根混入heldout目标。

本地六臂只保留 `final` 权重；manifest 实际 `save_every=256`，49个分数输出不等于49个可重新推理的模型。要补采中间时刻必须先核实云端是否仍保留权重，否则需锁定设置重跑并保存所需检查点。这是真正需要云端/GPU的新证据，不是继续 CPU 重采既有32根能补出的信息。

复现命令：`python certify.py`，随后 `python verify_independent.py` 和 `python audit_design.py`。分别重算六臂/区间/校准/8000模拟、独立复查完整秩输出、核验抽样与训练档案。所有产物均在本目录。
