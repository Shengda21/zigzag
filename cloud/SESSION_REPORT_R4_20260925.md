## 1. 统计程序修订（论文 §3.3）

- **原程序的问题**：逐转移端点数 + 相邻检查点置换。在第一次确认的全部臂上最小 p = 0.35–0.41，无一显著。诊断表明这不是实现问题：打乱时间轴会在每个转移处制造大量端点（全局打乱后是观测值的 5–7 倍），所以逐转移统计量对真实阶跃没有检验力。
- **新程序**：
  - S2 题目簇 bootstrap（B = 1000，同一重抽样作用于全部检查点）：判据需"点估计成立且支持度 ≥ 0.95"；
  - S3 全局时间组织检验：端点总数下尾，检查点全局置换，B = 1000；
  - 跨臂复现。
- **实现**：`crosslingual/code/zz_robust.py`。点估计与 zz_analyze 逐项一致；游程压缩的 zigzag 分解与原算法在 128/128 个用例上完全一致，速度约快 1000 倍。

## 5. Pythia-1.4B 公开检查点（外部效度）

- **检查点**：预注册 55 个，实际完成 33 个（1k–76k 连续网格 + 143k）。完成约一半后实例网络持续降到约 0 MB/s（镜像与代理都是）。按事先定的规则（只按网络情况决定、不看结果）再等了 90 分钟，只多完成 2 个，于是停止。这是对预注册的偏离，如实记录。
- **分析口径**：主分析用全部 33 个检查点；敏感性分析用计划网格的最长连续前缀 1k–76k（32 个）。两者结论相同。
- **H_P1（稳健退出）：不成立。** 点估计有 22 次退出（连续缺席 ≥ 2 个检查点），但在 B = 1000 的 bootstrap 下没有一次达到 0.95，都是阈值附近的抽样波动。
- **S3**：p = 0.001，拓扑轨迹在预训练时间上有组织。
- **P2**：θ = 0.6 时 zigzag 的有限 H₀ 条 8 条、单调化 5 条，差异来自上述非稳健的波动；两者都没有 H₁ 条。
- **P4**：
  - 稳健的事件是能力出生（H₀ 合并）：θ = 0.6 时 `e_iso_us` 7k（支持度 1.00）、`e_caesar3_caesar3upper` 8k（1.00）、`e_word_upper` 9k（0.98）、`e_iso_text` 22k（0.96）等；
  - 没有任何 H₁ 减少事件：日期三角的三条边与一致性面几乎同时出现，从未形成环。这与 SFT 线中"边与面同时学会"的现象一致。
- **结论**：在这个 49 胞腔复形与这个检查点粒度下，Pythia-1.4B 的预训练轨迹近似嵌套：学会的原子能力没有被稳健遗忘。论文 §3.2 的非嵌套前提目前只在有干预的课程（FORGET3）中得到确认；在预训练中，本检验没有找到支持。图：`analysis_r4/figures/pythia_1.4b_cells.png`。
