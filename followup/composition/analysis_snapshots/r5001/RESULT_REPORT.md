# R5001：独立训练种子的最低充分阶对照

两个世界各三个独立 LoRA 初始源；每个源配对比较等长度、等 token、等更新数、等算子曝光的二算子／三算子续训。所有源模型和端点均保留。该实验检验固定训练预算下的构造性充分性，不能从二算子组失败推出所有二算子训练方法都不可能成功。
