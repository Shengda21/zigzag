# C 行为诊断：匹配边结果、输出字段与独立根题目预测

日期：2026-11-08。分析是事后、本地 CPU 重分析；原始评测、预注册、论文均未修改。代码为 `analyze_behavior.py`，完整结果为 `results.json`，报告生成器为 `write_report.py`。

## 直接结论

原 E3 的“最弱边边际准确率高于面准确率”不足以证明额外的联合失败。在同一模板、同一根题目、实际所需输入上比较，保持分支的面成功率在六臂均不低于三条边实测结果的合取成功率，差为 0.0018–0.0809。替换分支还必须扣除题干已直接给出中间状态这一条件；相应两边基线的差异见下表。存在逐题不一致，但不支持把原边际差解释为独立高阶学习机制。

独立根题目的 C 修复任务提供一个真实但探索性的正结果：在整世界留出预测中，加入面分数改善修复准确率的预测；对 C 三跳链没有一致改善。这里检验的是额外测量的预测价值，没有检验拓扑摘要优于带标签分数，更没有建立机制或因果优势。

## 可比性、训练重叠与确定性捷径

- 六臂共 294 个压缩逐题文件，49 个检查点、三个世界各两个训练种子。每世界的结构根题目 32 个，独立根题目另有 32 个；两个种子复用相同题目。
- 逐世界读取 MANIFEST 中的实际置换，并对每个检查点逐题核对 gold：C1C2、C2C3、C1C3 均为恒等索引置换。保持分支的三条边可用同一根题目配对；替换分支中间及路径终点用 `other` 根题目，直接终点仍用原根题目。`other` 是 32 根题目循环中的下一个。
- 保持分支准确比较：模板0的三个独立边回答是否全部正确，对模板0面的四字段整体正确。模板3也单独分析；这是未用于训练的措辞模板，但已被原实验评测，不能称新封存确认集。原主得分混合了边模板0/1，而面只有模板0，因此原得分差还有模板构成差异。
- 替换分支题干直接提供实际中间序列。所需独立边仅为直接 C1→C3(root) 与 C2→C3(other)，中间字段可从题干复制。另列三个边合取供结构配对，但其中 C1→C2(other) 并非额外必需的推理步骤。
- 保持分支 gold 的直接与路径终点完全相同；第四字段恒为1。替换分支第四字段恒为0，因为 other 与 root 不同且映射可逆。因此第四字段不是独立组合推理测量；保持分支还有重复输出捷径。
- 读取真实 TRAIN_STREAM 检查：结构/独立二元根题目与训练 primary root、other/bad 均零重叠。原子代码符号与词典故意共享，不是未见符号泛化。联合任务本身训练过，各世界 fC123 训练记录数为3035、3082、3065（两个种子共用该世界流）；修复和链任务类型也训练过。

## 额外分数的外部预测价值：有真实独立根标签

目标为独立根题目上的 `chain_C1_C2_C3_C4` 整体准确率，及 `repair_fC123` 三种错误条件的整体准确率均值。它们不参与上述 C 胞腔分数，每世界32个独立根题目与结构/训练根题目不交。修复条件共享同一根，始终作为一个簇重抽；这些标签不是全新未读确认数据。

固定模型为标准化输入的 Ridge，正则系数1；截距不惩罚、输出截到[0,1]。未搜超参数。基线含训练步比例及平方、固定课程节点128/288/352/480/544的阶段指示、四条 C 边分数（模板0/1平均）、三角形边最小值及乘积。增广模型再加入面保持/替换分数及二者最小值。每折两个世界拟合、第三世界两个种子共同留出；全部49检查点用于各世界，但绝不随机拆分检查点或种子。标准化仅在该折训练世界拟合。

500次重抽独立地抽结构根与外部目标根，既定世界两个种子共享权重，重做三折全部拟合；另做250次循环块8重抽，考虑替换/修复 other、bad 的重复使用。这里只估计固定三个世界下题目重抽的变化。三个世界都来自同一课程/生成机制，不能据此给世界总体置信结论。三折均修复有改善，但 C 链在637世界变差，汇总没有正证据。事后挑目标/模型与已阅读历史结果的选择偏差未被这些区间校正。

修复任务与面共享代码词典、输出/路径语义和训练机制。这个结果可称“根题目不交的修复行为预测诊断”，不能称跨机制迁移、独立确认或拓扑不可替代性；新增的是面测量，模型根本没有使用同调量。

## SIMODS 就绪度的独立判断

仍不足以诚实地宣称达到 SIMODS 投稿就绪。理论保持不变、只补充余核持久模与经典工具的关系备注，有助于正确定位，却不增加核心数学推进。此次精确配对削弱了原 E3 的高阶机制解释；修复预测改善是一个值得保留的实际正证据，但只涉及三个世界、同一课程，且无需拓扑即可获得。因此无法据此补上评审指出的数学原创性或一般方法价值缺口。

建议论文把原边际差降级为测量构成诊断，增加精确合取负结果与探索性修复预测的窄结论。下一轮 E4 若执行，需独立生成不循环复用的根对、匹配真实必需字段及输入、把输出复制/格式捷径纳入对照，并在新世界冻结目标和非拓扑完整标签基线；若这些检验不支持拓扑增益，应报告阴性。当前真实进展是排除了一个误导性比较，并找到了可供新确认实验检验的修复预测现象，不能以修辞包装为已解决投稿门槛。

## 复现与内置核验

运行 `python analyze_behavior.py`，再运行 `python write_report.py`。读取原始294文件并断言：每世界根集合不交、置换恒等、所有 face gold 字段与实际配对边 gold 一致、other循环对应、每独立目标每根的条件数固定。输出仅在本目录。报告另外核对每支544观察与六臂保持支净差非正；这不是新增训练或模型实验。

额外逐输出复核：对相关 C 边、面及两个外部目标的 188,160 条真实 prediction，调用原评分器重新评分；correct、valid_format 与 field_correct 三项全部逐条一致。
