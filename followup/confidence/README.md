# confidence

Post-hoc finite-population confidence diagnostic: real_results.json and design_matched NPZs. IID counterfactual NPZs, simulation_results.json and sample_calibration.json are separately labelled hypothetical/simulated evidence, not confirmations.

See [the followup README](../README.md) for exact input paths, commands, seeds and manuscript-label mapping. Sources are preserved unchanged; execute through `python followup/run.py confidence/certify.py` from the repository root.
